# Precision manufacturing PO fixtures

Six synthetic purchase-order fixtures for parser evaluation. All companies, people, addresses, telephone numbers, order identifiers and commercial data are fictional. They are not valid orders.

The set varies company presentation, line-item density, pagination, currency, Incoterms, unit of measure, discounts, and a scanned image-only document. The digital PDFs retain a text layer; `pm06` intentionally does not. Each PDF has a same-name JSON expected result.
